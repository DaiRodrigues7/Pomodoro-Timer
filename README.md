# Solune Pomodoro Timer

Um timer pomodoro mágico e fofo para ajudar você a manter o foco e aumentar sua produtividade.

## 🌙 Sobre o Solune

O Solune Pomodoro Timer combina o poder do método pomodoro com uma interface encantadora e sons mágicos. Perfeito para estudantes, profissionais e qualquer pessoa que queira gerenciar seu tempo com estilo.

## 🚀 Começando

### Pré-requisitos

- Node.js (versão 14 ou superior)
- npm ou yarn

### Instalação

```bash
npm install
```

### Scripts Disponíveis

No diretório do projeto, você pode executar:

### `npm start`

Inicia o aplicativo em modo de desenvolvimento.\
Abra [http://localhost:3000](http://localhost:3000) para visualizar no navegador.

A página recarregará automaticamente se você fizer edições.\
Você também verá erros de lint no console.

### `npm run build`

Compila o aplicativo para produção na pasta `build`.\
Otimiza o build para melhor performance.

O build é minificado e os nomes de arquivos incluem hashes.\
Seu aplicativo está pronto para deploy!

### `npm test`

Inicia o test runner em modo interativo.

## ✨ Características

- 🎯 **Timer único**: Foco simplificado em uma única sessão
- 🎵 **Sons mágicos**: Notificações encantadoras para cada evento
- 📊 **Estatísticas precisas**: Acompanhe seu progresso diário
- 🌙 **Tema Solune**: Design fofo com cores pastel
- 💾 **Persistência**: Dados salvos automaticamente
- 📱 **Responsivo**: Funciona perfeitamente em todos os dispositivos

## 🎨 Personalização

O Solune usa uma paleta de cores inspirada no sol e lua:

- **Sol**: Laranja pastel (#FFB366) e amarelo suave
- **Lua**: Violeta suave (#9333EA) e lilás

## 📝 Como Usar

1. Defina seu tempo de estudo nas configurações (10-60 minutos)
2. Clique em Play para iniciar sua sessão
3. Mantenha o foco até o tempo acabar
4. Faça uma pausa quando necessário
5. Acompanhe suas estatísticas e metas diárias

## 🛠️ Tecnologias

- React com TypeScript
- Framer Motion para animações
- TailwindCSS para estilização
- Lucide React para ícones
